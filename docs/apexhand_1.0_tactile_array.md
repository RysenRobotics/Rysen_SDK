## 阵列映射详述

下图展示了 URDF 关节、触觉区域的命名，并以红框内的触觉阵列为例标出了阵列坐标方向：

![ApexHand 触觉区域与阵列坐标方向](images/apexhand_tactile_layout_and_axes.png)

阅读后续映射矩阵时，请对照图中的红色坐标箭头：X 正方向指向图中右侧，对应矩阵的列索引从左至右递增；Y 正方向指向图中下方，对应矩阵的行索引从上至下递增。

> **正整数索引为合法索引**。

> **`-1` 表示未安装传感器的无效采样点，触觉模块不会对该位置进行采样或更新。**

所有阵列映射中，仅手掌的阵列映射区分左右手，请注意选用正确的映射。
